# Архитектура

```
 access.log ──┐                                   ┌── консоль
              ├─ parsers ─► Event ─► Engine ─► Alert ─┼── JSON Lines
 auth.log ────┘             (общий вид)  │            ├── SQLite ─► report / blocklist
                                          │            └── Telegram
                                          └── Rule × 8 (скользящие окна по IP)
```

1. **Парсеры** превращают строку в `Event` (время в UTC, IP, тип, путь, статус и т. д.).
   Строки не по формату не падают с ошибкой, а считаются в `ParseStats.ignored`, и число выводится в итоге.
   Если в отчёте «не подошло» почти все строки, значит, формат лога другой.
2. **Engine** сортирует события по времени и отдаёт каждое всем правилам. Он пропускает доверенные адреса и объединяет повторы:
   одно и то же правило на тот же IP в пределах `cooldown_seconds` (300 с) увеличивает счётчик `repeats` у первого алерта.
3. **Правила** хранят скользящие окна по ключу (IP) в `SlidingWindow`. Время берётся из событий, а не из системных часов.
   Так результат повторяем, и правила можно тестировать, не дожидаясь реального времени.
4. **Sinks** получают алерты по одному. Ошибка отправки в Telegram не останавливает разбор, а токен не пишется в лог.
5. **Storage** хранит алерты в SQLite с параметризованными запросами.

## Режимы

- `analyze` читает файлы целиком; алерты отдаются после того, как все повторы объединены.
- `follow` проверяет файлы раз в `--poll` секунд (`Tailer`); алерт отправляется в момент первого срабатывания,
  повторы счётчиком не обновляются в уже отправленном сообщении.

## Принятые решения

- **Только стандартная библиотека.** Проект можно запустить на любом сервере без `pip install` зависимостей.
- **Время по логам.** Окна считаются по времени событий; события из разных файлов сортируются вместе. Для логов sshd
  нужно указать год и часовой пояс (`--year`, `--ssh-tz-offset`), потому что в классическом syslog их нет.
- **Нет автоблокировки.** Ложное срабатывание не должно отрезать настоящего пользователя; блок-лист создаётся файлом для проверки.
- **Названия месяцев разобраны вручную**, чтобы результат не зависел от локали системы.
